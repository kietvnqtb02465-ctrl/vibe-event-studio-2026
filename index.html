Xác Nhận Tạo Sự Kiện Mới?

Thao tác này sẽ làm mới toàn bộ thông tin sự kiện trên form và đưa trang về trạng thái ban đầu để bạn tạo landing page mới. Bạn có chắc chắn muốn tiếp tục?

Hướng Dẫn Triển Khai Trong 3 Bước

Sẵn sàng chạy offline hoặc public lên Vercel / GitHub Pages

Link Gửi Cho Khách Tham Dự (Khóa Soạn Thảo)

Gửi link có đuôi ?view=live cho khách. Người tham dự chỉ xem trang sự kiện và đăng ký nhận vé VIP, toàn bộ thanh công cụ Soạn Thảo & Đổi Diễn Giả sẽ được ẩn tuyệt đối.

1 Chạy Cục Bộ (Local Run) - 0 giây cài đặt

Chỉ cần nhấp đúp trực tiếp vào tệp index.html để mở trong Chrome, Edge hoặc Safari. Mọi tính năng AI Synthesis, Countdown Timer, E-Ticket và LocalStorage hoạt động 100% trơn tru không cần Node.js.

2 Triển Khai Lên Vercel (Miễn phí trong 30 giây)

Cài đặt npm i -g vercel và chạy lệnh vercel deploy --prod tại thư mục này, hoặc kéo thả thư mục vào dashboard vercel.com/new để nhận ngay tên miền HTTPS công khai.

3 Triển Khai Lên GitHub Pages

Tạo repository mới trên GitHub, đẩy file index.html lên nhánh main. Vào mục Settings > Pages và chọn deploy từ nhánh chính. Trang web sự kiện sẽ online ngay lập tức!

Cấu Hình Hệ Thống Bản Thảo Thông Minh

* Khóa API được lưu cục bộ trong LocalStorage trình duyệt của bạn. Nếu API ngoài gặp sự cố, hệ thống sẽ tự động fallback về AI cục bộ mà không làm gián đoạn.

Tính năng Offline AI sẵn có: Sử dụng bộ quy tắc AIDA (Attention - Interest - Desire - Action) phân tích ngữ nghĩa từ khóa sự kiện và sinh nội dung tức thì 0ms mà không bắt buộc có API Key!
